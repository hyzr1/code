# Hyzr Code

A browser-based learning platform for Python, data structures and algorithms,
machine learning, and technical interview preparation.

The Algo workspace includes NeetCode 250, NeetCode 150, and Blind 75 study
lists with a local Python runner, official examples, hidden checks, progressive
hints, saved drafts, and reference solutions.

[code.hyzr.ai](https://code.hyzr.ai)

```bash
npm install
npm run dev
```

Regenerate the interview catalog from the MIT-licensed NeetCode source and
current LeetCode metadata with `npm run content:interview`.

Run `npm run check` and `npm run build` before deploying.
