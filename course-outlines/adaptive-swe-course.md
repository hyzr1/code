# Adaptive Software Engineer Course

## Product rule

The released product is one Software Engineer course. Python Mastery, Algo
Mastery, and ML Mastery remain visible as **Coming soon** until their complete
lecture, practice, visual, and narration sets pass the release gates.

The SWE path is not “finish every lecture before building.” It alternates
short instruction, retrieval, coding, projects, and interview practice.

## Shared Python core

Every company target receives the same 50 authored lessons:

1. Python from first principles
2. Fluent Python
3. Production Python

Changing company never removes these lessons and never resets progress.

## Adaptive depth

| Level | Path | Lessons | Interview practice target | Systems depth |
| ---: | --- | ---: | --- | --- |
| 1 | Focused preparation | 59 | 30–50 reviewed problems | API boundaries |
| 2 | Strong general preparation | 64 | 55–80 reviewed problems | Essential production reasoning |
| 3 | Highly competitive | 69 | 90–120 reviewed problems | Practical systems foundations |
| 4 | Elite bar | 73 | 130–170 reviewed problems | Full systems foundations |
| 5 | Frontier bar | 73 | 180–220 reviewed problems | Deep systems reasoning and harder variants |

Levels 4 and 5 share the full lecture set. Level 5 earns its extra depth through
harder variants, challenge problems, stricter cold-recall expectations, and
deeper project/system reviews—not duplicated lectures.

## Interpretation

Company placement is a preparation default, not an employer ranking or hiring
guarantee. Interview difficulty varies by role, team, location, and year. The
learner can switch companies at any time.
